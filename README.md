# DaiYu-Agent（黛玉Agent）

黛玉Agent 是面向 Cursor 与 Codex 的通用多 Agent 软件工程 Skill。简称“黛玉”，旧称“六闸”。

## 核心能力

- Goal 驱动的六阶段交付：摸底、方案、并发开发、审查、安全测试、收口。
- ③ 阶段强制至少两个 Agent 并发，支持 FE/BE 或实现/验证组合。
- Agent Registry、Control Plane、heartbeat、fan-out/fan-in、幂等重派和结构化证据。
- DevUI 默认前端规范、项目特性驱动的后端技术栈选型、Token 预算治理。

## 触发词

`黛玉`、`黛玉 连续`、`继续黛玉`；兼容 `六闸`、`6gates`、`solo-team`。

## 安装

将 `DaiYu-Agent` 目录复制到 `~/.codex/skills/` 或 `~/.cursor/skills/`，运行 `scripts/selfcheck.ps1` 验证。

仓库：<https://github.com/vx-zsck2020/DaiYu-Agent.git>

## 兼容迁移

历史工作区 `work/six-gates`、旧口令和旧别名继续有效；新安装目录统一为 `DaiYu-Agent`。
